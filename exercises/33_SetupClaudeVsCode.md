# Setup Claude in VS Code

If you have a Claude code subscription you can easily add Claude to your VS Code development IDE. Simply follow the following steps.

1. Open VS Code and go to Extensions
2. Search for an extension called `Claude Code for VS Code`
3. Click install. This will add the Claude plugin to your VS Code environment
4. You will now see Claude icon at the top right hand side of your VS Code window. Click the icon and it will open up a window to the right side of VS Code.
5. Authorise your account to enable Claude code.

## Install Claude Desktop app

Additionally, you can install the Claude desktop app and use Claude within the app. Please go to the following link to download the desktop app https://support.claude.com/en/articles/10065433-install-claude-desktop

## Use Claude in Terminal/Command line

You can also use Claude in your terminal. Please refer to the following link and follow the steps there to setup Calude in your terminal.
https://code.claude.com/docs/en/terminal-guide

## Few basic Claude commands

`/int` : Scans your codebase and generates a CLAUDE.md context file
`/help` : Displays all available system commands and active skills
`/clear`: Wipes the current chat history to reset context and memory
`/compact`: Compresses long conversations to save token usage
`/cost`: Shows the financial token consumption for your active session
`/exit`: Safely terminates the interactive Claude session
`/context`: Visualizes what files or text are currently filling your token window

You are all set now and ready to start coding with Claude.
