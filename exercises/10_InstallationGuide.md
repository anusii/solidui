# Installation Guide

To get started with our Flutter based Solid tooling, we recommed you install the following.

1. Installing VS Code: https://code.visualstudio.com or Codium: https://vscodium.com/ is highly recommended. However, any Code OSS-based editor will work too.
2. Install Git for version control: https://git-scm.com/
3. Install Flutter: follow the official quick-install guide, which walks you through it per operating system: https://docs.flutter.dev/install - the quickest path is to open VS Code, install the "Flutter" extension, then run the "Flutter: New Project" command, which will offer to download the SDK for you.
4. Verify your setup: open a terminal and run `flutter doctor`. It reports anything still missing. 
5. If you are targeting the Android apps you need to install Android SDK. Easiest way to get Android SDK is to install Android Studio: https://developer.android.com/studio
6. If you are targeting Windows desktop apps you need to install Visual Studio Community edition: https://visualstudio.microsoft.com/downloads/ with "Desktop development with C++" workload.

## Getting Started with Solid
Our packages give you ready-made building blocks for Solid apps:
- solidpod (core logic for reading/writing encrypted POD data): https://pub.dev/packages/solidpod
- solidui (Flutter widgets for login, permissions, and more): https://pub.dev/packages/solidui
